# My Homeserver :D

Hello, I am Noa (binary) and today I show you my homeserver, what runs on it and so on.

### First of all the OS

I wanted a stable OS and on my old homeserver it ran on Ubuntu. It was okay but I had problems with Docker and the hardware
of the homeserver is not the newest (2010 hardware). I chose Debian because it's really stable, so I like to say Debian is like a 
really big and stable concrete block with almost no cracks.

### DOCKER CONTAINERSSS !!! cool stuff I love Docker

Now let's get to my Docker containers that I run. One is a self-coded web application and the other 4 are from the great open source community :D.

- 1. Cash-App (Created by myself 😎): So this is a web application where I can send all my receipts in to see where and when I spend my money on 
some new things like food, games or new hardware. Everything is listed on a webpage, also sorted by category. The detection of the receipts works over
two ways: the first is a rule parser so it tries to read, but the cooler method in my opinion is over an Ollama LLM (qwen2.5) and when it got everything it 
sends you to GitHub.

- 2. Portainer: So to the people that are new to like organizing containers and stuff like that, you neeeddd to try Portainer. It is a tool where you see all your containers and
you can do a lot with it.

- 3. Wireguard (VPN): I often am outside or not at home, like in school, a friend's house, or the library, but I need to work with something in my homelab so I can connect to 
my home network. And little life hack: in school a lot of domains are blocked like YouTube or AIs, to circumvent that you can connect to a VPN.

- 4. Ollama: As a student I don't have enough money for expensive API keys so I run Ollama on my homeserver to test things where I need an API key or
when I develop new apps or security tools (check out my repo Scry, very cool). I can use that.
